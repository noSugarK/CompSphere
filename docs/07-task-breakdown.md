# 07 开发任务拆解

**版本**：v1.7（2026-11-18）。集中部署，无固定上线日期；按任务依赖和验收交付。
拆分原则：每周结束都有可演示物；依赖方向 = 权限 → 组织/赛事 → 报名 → 获奖/证书。

v1.1 变更：新增日志基座、邮箱验证码、身份证加密、赛项/开放组合、公示名单、证书编号计数器等工作项，工期由 12 周增至 15 周（依据见文末「工期影响」）。

**编号约定**：`W1`…`W15` 是**任务包编号，不等于自然周**。一个任务包可以跨多周，多包也可在一周内并行。本轮增加W3a承接队伍基础，保留W5快照服务与W8首期交付入口；首期压测在W8验收，W15做后续扩展复测。旧版11/15周仅为历史估算，队伍前移、证书后移后重新估时。

---

> 本轮确认：队伍基础、逐赛季许可、团队报名、固定模板学生/队伍/成员导入前移首期；证书、复杂跨队特批、队伍准入与跨届审核上下文、两级审核后续实现。自动备份及可验证的人工恢复是首期门槛。

**首批实现记录**：正式工程、锁定依赖、严格JSON/AI回传校验、认证/RBAC、队伍提案/许可、报名冻结/单级审核核心及对应前端已建立；PG16安全与并发、前端schema/session测试和构建已验证。下列勾选框代表完整任务包，未因其中部分实现而整体勾选；实际能力和未完成项统一见各工程README，配置CI不等于远端已运行通过。
