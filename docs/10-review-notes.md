# 设计修复记录

修订日期：2026-11-17。当前仅设计文档、DDL 与部署草案；前后端尚未初始化，文档规则不等于已实现能力。

## 已确认规则

- 单位树权限不继承赛事权限；赛事创建和管理角色分配仅平台管理员。单位管理员统一管理本单位全部队伍，教练仅查看本单位队伍/代报本人负责队伍，无队伍资料或成员写权限；管理员交接仅变更角色并审计，不建立离职档案。
- 单位创建由平台审核；队伍创建及新赛季激活仅平台审核；资料/成员修改由另一名有权单位管理员或平台审核，禁止自审。队伍能力保留里程碑 2。
- 队号只能归属一个单位，队号×稳定赛项定义队伍；晋级准入跟随队伍身份；学生全平台仅一支当前队伍；本人可自主退队，同赛季同赛项绑定不释放，回原队可普通审核，跨队仅平台特批，保留成员和绑定变更历史。
- 仅冻结本场提交资料和成员，不冻结队伍主档；学段由提交人选择。未审可取消修改，已通过须先驳回再改，重提保留旧版并遵守时间窗。
- 身份证/护照二选一；证件更正允许所属单位管理员审核本范围普通成员，平台可审核，申请人/证件本人不得自审。批准才释放旧号并撤销旧会话；注销不自动释放当前绑定。
- 企业可代建无邮箱学生账户，证件+密码登录、首次改密；普通学生由当前有效主属单位核验重置；单位转移需学生授权、原单位转出、新单位接收，完成后切换重置权，禁止接管既有或管理账户。联系电话可共用，不采集专业。
- 团队按审核通过版本的参赛成员逐人发证，奖项只面向学生，无单位/组织/教练奖；关闭届次保留管理历史，普通入口隐藏，公开证书验证保留最小结果。
- 赛季独立配置起止日期，可跨年并行；赛事场次必须归属赛季。防串队按赛季×稳定赛项×学生约束，单场关闭不释放；平台切换唯一当前赛季，普通端只读展示；队伍按季注册许可，不能跨季继承，关闭业务历史仍仅授权管理可见。
- 中英、主题与私有证件照纳入里程碑 1；当前仍待初始化实现。
