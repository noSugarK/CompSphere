## 已确认决策

- 单位角色只覆盖本单位树，不继承关联赛事权限；赛事由平台管理员创建并指定管理员，单位管理员不能禁用账号或分配管理角色。
- 团队按冻结报名成员逐人发证（不自动给教练发证），个人报名同样逐人；补发仍属于同一获奖记录与成员。
- 仅参赛成员填写证件；任何 API 不回传完整证件号。注销后哈希仍占用，重新参赛走原账号恢复；联系电话可共用，专业字段停止采集。
