# 09 开源参考与采用边界

本文件只保留选型入口。旧稿的 star 数、活跃度、同类项目“唯一/不存在”结论及逐项许可证判断缺少版本化证据，已移除，不作为设计依据。

## 1. 已选基础设施

| 能力 | 官方来源 | 本项目用途 |
| --- | --- | --- |
| 组织树 | [django-treebeard](https://github.com/django-treebeard/django-treebeard) | 组织物化路径与子树查询 |
| 导入导出 | [django-import-export](https://github.com/django-import-export/django-import-export) | Resource、dry-run、行级错误；Celery 中调用 |
| 证书 PDF | [WeasyPrint](https://github.com/Kozea/WeasyPrint) | HTML 模板生成 PDF，中文字体随镜像部署 |
| UI 组件 | [Element Plus](https://github.com/element-plus/element-plus) | 表格、表单、抽屉；主题遵循根目录前端规范 |
| 配色 | [Radix Colors](https://github.com/radix-ui/colors) | 语义颜色令牌 |

版本在 W1 按 Python/Django/Node 兼容矩阵锁定；表中来源不代表本轮已核验某个版本的许可证。

## 2. 概念参考

- [Indico](https://github.com/indico/indico)：投稿、评审与决议流程；不视为 Django 实现样例。
- [pretix](https://github.com/pretix/pretix)：报名、订单变更留痕；业务概念需转为本项目自己的模型。
- [PyCasbin](https://github.com/casbin/pycasbin)：Python 权限策略实现；不是必须经 Go 内核绑定。当前按 02 文档实现可测试的 scope 解析，不额外引入策略引擎。
- [Open Badges](https://www.imsglobal.org/spec/ob/v3p0)：撤销与验证语义；第一版不实现完整标准。
- [vue-element-plus-admin](https://github.com/kailong321200875/vue-element-plus-admin)：外壳与页面组织参考；不直接继承其角色安全模型。
- [eventyay](https://github.com/fossasia/eventyay)：若采用，检查其实际版本的 LICENSE、NOTICE 与文件来源；文件名或字符串提及另一项目不足以证明授权有问题。

## 3. 采用检查

1. 使用依赖或复制源码前，记录官方仓库、准确版本/commit、LICENSE/NOTICE 链接及拟使用方式。
2. 保留相应版权和 NOTICE；涉及 AGPL 或额外署名条款时，确认分发/网络服务义务与交付方式是否兼容，再决定使用。
3. “可学习概念”不等于“可直接复制实现”；任何许可证标签都不能替代对锁定版本条款的核对。

核验记录随实际依赖落地，不维护易过时的 star 排名或未经源码验证的能力断言。
